# Hardened Slime Block

[English](#english) | [中文](#chinese)

---

## English

**Hardened Slime Block** is a [fabric-carpet](https://github.com/gnembon/fabric-carpet) extension for Minecraft **Java Edition 26.1.2** that lets you selectively disable the slime block's *bounce* and *slowdown* effects — **for players only**. Every other entity (mobs, items, minecarts, boats, projectiles, ...) keeps 100% vanilla behavior.

### Requirements

| Component | Version |
|---|---|
| Minecraft | 26.1.2 |
| Fabric Loader | 0.19.5+ |
| fabric-carpet | 26.1 branch (e.g. `26.1+v260402`) |
| Java | 25+ |

### Usage — two independent rules

| Rule | Default | Effect when `true` |
|---|---|---|
| `slimeBlockNoPlayerBounce` | `false` (vanilla) | Players no longer bounce when landing on slime blocks |
| `slimeBlockNoPlayerSlowdown` | `false` (vanilla) | Players are no longer slowed down while walking on slime blocks |

```mcfunction
# toggle at runtime (no restart needed)
/carpet slimeBlockNoPlayerBounce true
/carpet slimeBlockNoPlayerSlowdown true

# persist a new default into the world's carpet.conf
/carpet setDefault slimeBlockNoPlayerBounce true
/carpet setDefault slimeBlockNoPlayerBounce false
```

Both rules are hot-swappable, categorized under `survival` / `feature`, and translated (en/zh_cn).

### How it works

Two `@Inject` handlers on `SlimeBlock`:

- `updateEntityMovementAfterFallOn` → when the bounce rule is on and the entity is a `Player`, replicates `Block`'s default landing behavior (zero out Y velocity) — identical to vanilla sneaking-landing.
- `stepOn` → when the slowdown rule is on and the entity is a `Player`, cancels the vanilla horizontal slowdown. `Block#stepOn` is a no-op, so cancellation has no side effects.

Any entity other than a `Player` never passes through these interceptions. Players riding boats/minecarts/horses are subject to the *vehicle's* physics, which stay vanilla. Fall damage cancellation, piston sticking and all other slime block traits are untouched.

### Building

```bash
gradlew.bat build   # Windows (requires Java 25, e.g. GraalVM 25)
./gradlew build     # Linux / macOS
```

The jar lands in `build/libs/`.

## Chinese

| 组件 | 版本 |

### 用法 —— 两条独立规则

| 规则 | 默认值 | 开启（true）时效果 |
|---|---|---|
| `slimeBlockNoPlayerBounce` | `false`（原版） | 玩家落在粘液块上不再弹跳 |
| `slimeBlockNoPlayerSlowdown` | `false`（原版） | 玩家在粘液块上行走不再减速 |

```mcfunction
# 运行时切换（无需重启）
/carpet slimeBlockNoPlayerBounce true
/carpet slimeBlockNoPlayerSlowdown true

# 把新默认值固化到世界 carpet.conf
/carpet setDefault slimeBlockNoPlayerBounce true
```

### 实现原理

对 `SlimeBlock` 做两处 `@Inject`：

- `updateEntityMovementAfterFallOn` → 弹跳规则开启且实体为 `Player` 时，复刻 `Block` 的默认落地行为（竖直速度清零），与原版潜行落地一致。
- `stepOn` → 减速规则开启且实体为 `Player` 时，取消原版水平减速。`Block#stepOn` 本身为空实现，取消无副作用。

玩家以外的实体完全不经过这些拦截。玩家乘船/矿车/骑马时受**载具**物理影响，载具行为保持原版。摔落伤害归零、活塞粘连等其他粘液块特性一概不动。
